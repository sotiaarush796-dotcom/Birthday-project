# Master Project Brief

## Goal
Create a deeply personal 21st-birthday web experience that feels like an interactive love story rather than a conventional birthday page.

## Emotional arc
Playful → nostalgic → intimate → musical → emotional → mysterious → deeply personal.

## Core sections

### 01 — Opening
- Cinematic welcome
- Her name / 21st birthday
- Warm scrapbook environment
- Teddy motif
- Soft entrance animation
- Clear invitation to begin

### 02 — Love Gallery
- Polaroid-style photographs
- Categories for different types of memories
- Full-screen photo viewer
- Smooth transitions
- Optional captions/notes

### 03 — Our Timeline
- Horizontal scrolling
- Events represented by hanging photographs
- Threads, clips and subtle movement
- Each event opens a dedicated memory collection
- Each collection may contain photos, notes, video and/or an Easter-egg clue

### 04 — Our Songs
- Large interactive vinyl disc
- Five selectable tracks
- Disc rotates while music plays
- User interaction required before audio starts
- Each track has a private keyword/clue
- Keyword system can unlock hidden content

### 05 — People Who Love You
- Main edited birthday montage
- Individual family/friend messages
- Film/scrapbook presentation
- Strong emotional pacing

### 06 — Easter Egg System
- At least one subtle discovery per major section
- Discoveries should feel organic, not like obvious buttons
- Clues can connect across sections
- Final discovery should have emotional payoff

### 07 — Love Letter
- Hanging envelope / letter
- Click/tap to open
- Handwritten-style reveal
- Minimal, intimate presentation
- Optional final reveal after the letter

## Design principles

1. Personal over generic.
2. Subtle over excessive.
3. Photography is the emotional hero.
4. Animation should support the story.
5. No visual clutter.
6. Avoid excessive hearts, glitter, gradients or stereotypical Valentine's graphics.
7. Reuse motifs so the website feels like one world.
8. Mobile must feel intentionally designed, not merely responsive.

## Technical principles

- Keep content data-driven.
- Separate content/assets from UI components.
- Keep interactions modular.
- Avoid unnecessary dependencies.
- Optimize images/video/audio.
- Never expose secrets in client code.
- Preserve working behavior when modifying the project.
